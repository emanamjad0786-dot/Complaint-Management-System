
# Complaint Management System

## Project Description
The Complaint Management System is a console-based C++ project developed using Object-Oriented Programming (OOP) concepts. It allows users to manage complaints easily through different options.

## Features
- Add a new complaint
- View all complaints
- Search complaints by ID
- Search complaints by username
- Delete complaints
- Update complaint status
- Admin complaint management
- Staff complaint resolution

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Single Inheritance
- Multilevel Inheritance
- Multiple Inheritance
- Function Overloading

## Technologies Used
- Programming Language: C++
- Concepts: Object-Oriented Programming (OOP)

## How to Run
1. Download or clone this repository.
2. Open the C++ file in any C++ IDE.
3. Compile and run the program.
4. Use the menu options to manage complaints.

## Storage
The project uses an array to store up to 100 complaints during program execution. Data is not permanently saved.

## Project Purpose
The purpose of this project is to understand and implement basic OOP concepts through a real-world complaint management example.
